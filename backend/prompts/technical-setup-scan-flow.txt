[TASK]
Search the latest technical data for the given stock list and tag each stock with the most relevant approved bullish or bearish technical setup.

[ROLE]
Act as a top-tier technical analyst and swing-trading strategist.

[OBJECTIVE]
Produce one table assigning each stock a Primary Setup, optional Secondary Setups, Bias, Confidence Score, Trigger Level, and Invalidation Level.

[MARKET + TIME HORIZON]
Market: `{{MARKET_LABEL}}`. Exchange scope: as provided in `{{STOCK_ROWS}}`. Daily chart primarily, weekly chart where useful. Swing relevance: 1–3 months.

[INPUTS]
`{{MARKET_LABEL}}`
`{{STOCK_ROWS}}`
`{{APPROVED_TECHNICAL_SETUPS_MARKDOWN}}`

[DATA + SOURCE RULES]
Use fresh internet data only. Prefer TradingView, StockCharts, Yahoo Finance, MarketWatch, Investing.com, Screener, NSE/BSE, Nasdaq, Trendlyne, Chartink, StockEdge, or reliable chart sources.

[COVERAGE RULES]
Every stock must receive one Primary Setup exactly matching the approved Technical Setups list. Secondary Setups are optional and must also exactly match approved setup names.

[ANALYSIS RULES]
Check latest price action, daily/weekly chart, moving averages, volume, RSI/divergence, support/resistance, breakout/breakdown levels, 52-week high/low position, and trend strength.

[DECISION RULES]
Bias must be Bullish, Bearish, or Neutral. For bearish setups, treat as sell/trim/avoid fresh buying/exit weak holdings, not short-selling. Confidence Score must copy the numeric approved confidence for Primary Setup.

[CAPITAL / UNIT RULES]
Not applicable. Do not provide allocations, units, position sizes, or trade quantities.

[OUTPUT FORMAT]
Return exactly this table:

| Exchange Symbol | Stock Symbol | Primary Setup | Secondary Setups | Bias | Confidence Score | Trigger Level | Invalidation Level |
| --------------- | ------------ | ------------- | ---------------- | ---- | ---------------- | ------------- | ------------------ |

[FALLBACK RULES]
If data is incomplete, still assign closest valid Primary Setup from approved list. If trigger or invalidation cannot be verified, write `Not found`.

[VALIDATION CHECKLIST]
Verify every input stock appears exactly once; every setup exactly matches approved list; Confidence Score equals approved value; Bias is valid; levels are specific or Not found.

[FINAL OUTPUT RESTRICTION]
Return only one markdown table. No introduction, explanation, notes, bullets, summary, conclusion, or code fences.
