[TASK]
Create one markdown table listing all upcoming scheduled or announced price-sensitive events for current portfolio holdings.

[ROLE]
Act as an equity market calendar analyst for Indian equities and US equities.

[OBJECTIVE]
Identify upcoming earnings, results, board meetings, AGMs, dividends, buybacks, splits, bonus issues, rights issues, investor days, product events, regulatory events, and other scheduled company-specific catalysts.

[MARKET + TIME HORIZON]
Cover NSE/BSE and NASDAQ/NYSE/AMEX holdings. Prioritize nearest 60 calendar days from `{{SNAPSHOT_DATE}}`; include later events only if clearly scheduled and material.

[INPUTS]
`{{SNAPSHOT_DATE}}`
`{{PORTFOLIO_SNAPSHOT_AND_HOLDINGS_TABLES}}`
Exchange + stock symbol pairs are authoritative.

[DATA + SOURCE RULES]
Use latest web data. Prefer NSE/BSE announcements, company IR, SEBI/NCLT filings, SEC filings, Nasdaq/NYSE calendars, press releases, and reputable market calendars.

[COVERAGE RULES]
Cover every holding. Return at least one row for every holding. Include multiple rows if multiple material events exist.

[ANALYSIS RULES]
Assess expected event bias using recent results trend, expectations, guidance, management commentary, newsflow, sector trend, valuation, recent price action, and event type.

[DECISION RULES]
Expected Outcome must be exactly Bullish, Bearish, or Neutral.

[CAPITAL / UNIT RULES]
Not applicable. Do not calculate allocation, units, weights, or buy/sell actions.

[OUTPUT FORMAT]
Return exactly this table:

| Date | Exchange | Stock Symbol | Stock Name | Event | Why it may matter | Expected Outcome | Status / Source |
| ---- | -------- | ------------ | ---------- | ----- | ----------------- | ---------------- | --------------- |

Date format: DD Mon YYYY.

[FALLBACK RULES]
If no event is found for a holding, include one fallback row with Date `Not found`, Event `No upcoming scheduled price-sensitive event found`, Expected Outcome `Neutral`, Status / Source `Checked latest available sources`.

[VALIDATION CHECKLIST]
Verify every holding appears at least once; dates are upcoming as of `{{SNAPSHOT_DATE}}`; every row includes Exchange, Stock Symbol, Stock Name; Expected Outcome is valid.

[FINAL OUTPUT RESTRICTION]
Return only one markdown table. No introduction, explanation, notes, bullets, summary, conclusion, or code fences.
